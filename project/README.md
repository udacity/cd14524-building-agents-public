# UdaPlay — AI Research Agent for the Video Game Industry

Starter code for the UdaPlay project in Udacity's *Building Agents* course.

Everything you need is in [`starter/`](starter/): start with [`starter/README.md`](starter/README.md),
then work through `Udaplay_01_starter_project.ipynb` (Part 1, the vector database) and
`Udaplay_02_starter_project.ipynb` (Part 2, the agent), in that order, from the `starter/` folder.
